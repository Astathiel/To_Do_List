# Interactive To-Do List

## About this project
This To-do list application was created with HTML, CSS and JavaScript. It provides clean and fun interface for users to add and delete tasks. This project demonstrates the fundamentals of DOM manipulation. Showing how to dynamically create and delete HTML elements in response to user interactions.

## Features
* **Add Tasks:** A simple input form allows users to easily add new tasks to their list.
* **Mark as Complete:** Clicking on a task toggles its completion status visually marking it with a line-through and faded color for clear tracking.
* **Delete Tasks:** Each task has a delete button(visible on hover) that allows for easy removal form the list.
* **Input Valiation:** The application prevents empty tasks and auto-completion from being added to the list.

## How to use
Using the To-Do List:
1. **Add a task:** Type your task into the input field at the top and either click the "**Add task**" button or press the "**Enter**" key.
2. **Completion a Task:** Click anywhere on the task's text area. This will cross it out. Click it again to mark it as incomplete.
3. **Delete a Task:** Hover your mouse over the task you wish to remove and a red **x** button will appear on the right. Click this button to permamently delete the task.
